# FluorineOS Keyring

APT archive keyring and source configuration for FluorineOS 0.0.1.

## Contents

- /usr/share/keyrings/fluorineos-archive-keyring.gpg
- /etc/apt/sources.list.d/fluorineos.sources

## Package

- Name: fluorine-keyring
- Version: 0.0.1
- Architecture: all

## Build

```sh
dpkg-buildpackage -us -uc -b
```

This repository is part of the FluorineOS project.
